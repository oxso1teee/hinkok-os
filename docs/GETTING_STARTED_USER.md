# Первый день с HinkoK OS

Это руководство — не для того, кто деплоит проект (для этого есть
`docs/VERCEL_DEPLOYMENT.md`), а для того, кто им **пользуется** каждый день.

## Шаг 1: первая заметка через Telegram

Всё начинается в Telegram-боте — это основной способ что-то добавить в
систему, без необходимости открывать веб-дашборд.

Откройте чат с ботом и отправьте `/menu` (или `/start`), чтобы увидеть
краткую справку. Дальше — просто пишите обычным текстом, система сама
определит, что это: задача, запись в дневник, приём пищи, событие или
заметка.

Если хочется указать тип явно — есть команды:

| Команда | Что это | Пример |
|---|---|---|
| `/task текст` | Задача в CRM | `/task Позвонить дантисту завтра` |
| `/journal текст` | Запись в дневник | `/journal Сегодня было спокойное утро` |
| `/meal текст` | Приём пищи | `/meal Овсянка с бананом` |
| `/event текст с датой/временем` | Событие в календарь | `/event Завтра в 15:00 созвон по проекту` |
| `/note текст` | Просто заметка | `/note Идея для видео про...` |

Голосовые сообщения распознаются автоматически (текст расшифровывается и
дальше обрабатывается как обычный текст). Фотографии еды анализируются
автоматически — бот попробует оценить, что это за блюдо и примерную
калорийность/БЖУ.

После отправки бот отвечает подтверждением: куда попала запись и что с ней
можно сделать дальше (например, для задачи — кнопки для смены срочности).

## Шаг 2: увидеть это в дашборде

Веб-дашборд — там же, где настроен деплой (например
`https://<ваш-домен>.vercel.app`). Вход — по паролю (тому, что задан в
`DASHBOARD_PASSWORD`, плюс код из приложения-аутентификатора, если включена
двухфакторная аутентификация в Settings).

После входа — **HOME**: сводка на сегодня (ключевые задачи, календарь,
дневник, финансы за месяц). Дальше по верхней навигации:

- **CRM** — канбан-доска задач по срокам (сегодня / завтра / на этой неделе
  / и т.д.). Задача, отправленная через `/task`, появится здесь.
- **BRAIN** — обзор по сферам жизни (см. Шаг 3) и «Ask the OS».
- **JOURNAL** — дневниковые записи по дням, с настроением и текстом.
- **HEALTH** — метрики активности/сна (если подключена синхронизация).
- **STATUS** (`/operations`) — техническое здоровье фоновых задач (синки,
  бэкапы) — сюда обычно не нужно заходить каждый день, но полезно, если
  что-то работает не так.
- **SETTINGS** — идентичность, сферы, 2FA, интеграции (Google, Obsidian),
  активные сессии.
- **BACKUP** — ручной экспорт зашифрованного бэкапа всех данных.

## Шаг 3: что такое «сферы»

Каждая задача и заметка может относиться к одной из сфер жизни — это способ
увидеть баланс между разными областями, а не просто плоский список без
контекста:

Работа · Финансы · Здоровье · Отношения · Развитие · Сознание · Личное ·
Контент · Смыслы

Классификатор пытается определить сферу автоматически по тексту; если он
ошибся — можно поправить вручную при редактировании задачи.

## Шаг 4: зачем нужен «Ask the OS»

На странице **BRAIN** есть поле «Спроси что-нибудь о своих заметках,
решениях или планах…» — это семантический поиск по ВСЕЙ истории захватов
(и, если подключён Obsidian, по заметкам из вашего vault). В отличие от
обычного поиска по ключевым словам, «Ask the OS» понимает смысл вопроса и
даёт ответ со ссылками на конкретные исходные записи, из которых он собран
— не выдумывает факты, а честно опирается на то, что реально было
записано (и явно говорит, если подходящих записей не нашлось).

Пример: «Что я решил насчёт бюджета на ремонт?» — если раньше была
заметка или задача про это, ответ сошлётся именно на неё, с датой и
ссылкой открыть исходную запись.

## Что дальше

- Мобильный доступ (PWA, «добавить на экран домой») — см.
  `docs/MOBILE_USAGE.md`, если такой файл уже создан к моменту чтения,
  либо просто откройте сайт в мобильном браузере и используйте пункт меню
  браузера «Добавить на главный экран».
- Как экспортировать все свои данные или начать с чистого листа — раздел
  приватности в `docs/DATA_RETENTION.md`.
- Если что-то не работает — `/menu` в боте покажет список команд заново, а
  страница **STATUS** покажет, не упала ли фоновая синхронизация.
